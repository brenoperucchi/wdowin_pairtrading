    1. Importar deque de collections e criar _realtime_flow_cache = deque(maxlen=720).
    2. Adicionar uma struct ou classe FlowTick para registrar timestamp, win_price, e broker_flow.
    3. No loop `flow_snapshot_loop()`, além do snapshot de 5m/1m, registrar o snapshot atual (a cada 5 segundos) no _realtime_flow_cache.
    4. Implementar a função `calculate_synthetic_flow_score(window_seconds)` calculando:
       - FLN (Fluxo normalizado) = delta(buy - sell) / delta(buy + sell)
       - PERS (Persistência) = sum(FL_t-N:t) / sum(|FL_t-N:t|) para 10 subjanelas
       - CONC_DIR (Concentração Top 3 direcionada) para o período
       - ABS_DIR (Absorção direcional) se volume alto e delta preço baixo/oposto
       - Unificar no ScoreFluxo_t = 100 * (0.40 * FLN + 0.30 * PERS + 0.20 * CONC_DIR + 0.10 * ABS_DIR).
       - Fazer isso para 5s, 15s e 60s e tirar a média combinada ScoreFinal = 0.50 * Score_5s + 0.30 * Score_15s + 0.20 * Score_60s.
    5. Tratar divisões por zero ou limites de deques curtos (retornar 0.0 se dados insuficientes).
    6. Criar endpoint @app.get("/api/flow/realtime") que retorna a série histórica de deques contendo dicts com {"time": timestamp_unix, "value": score, "color": hex_color}.
       - Cores: Verde (#00e87a) para score >= 40, Vermelho (#ff3860) para score <= -40, Amarelo (#f5a623) para intermediários.
  </action>
