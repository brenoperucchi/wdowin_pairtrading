📄 PRD — Jumba Walls Replicator (Mini-Índice)
1. Visão Geral do Produto
1.1 Nome do Projeto
GEX Engine — Gamma Exposure Analyzer para Mini-Índice (WIN)
1.2 Objetivo
Desenvolver uma ferramenta proprietária que replique e expanda a funcionalidade do Jumba Trader, calculando e exibindo Gamma Exposure (GEX) para o contrato futuro de mini-índice IBOVESPA (WIN) a partir de dados públicos da B3 e do MetaTrader 5, eliminando a dependência de ferramentas de terceiros.
1.3 Problema que Resolve
Dependência de plataforma proprietária (Jumba Trader) para visualizar gamma walls
Impossibilidade de customizar cálculos, filtros ou lógica de classificação
Falta de integração nativa com o fluxo de operação no MT5
Custo recorrente de assinatura de ferramenta terceira
1.4 Proposta de Valor
1.5 Usuário-Alvo
Trader/analista que opera mini-índice (WIN) no MetaTrader 5 e utiliza análise de gamma para identificar zonas de suporte, resistência e mudança de regime de volatilidade.

F01 — Coleta de Open Interest da B3
Descrição: Download e parsing automatizado dos arquivos diários de posições em aberto da B3 para opções sobre IBOVESPA.
Regras:
Fonte: https://www.b3.com.br/pt_br/market-data-e-indices/servicos-de-dados/market-data/consultas/mercado-de-derivativos/open-interest/ ou arquivo FTP da B3
Formato esperado: CSV/TXT com campos: Ticker, Strike, Tipo (Call/Put), Vencimento, Open Interest, Preço Ajuste
Frequência: EOD (após 18h BRT)
Filtro: apenas séries de opções sobre IBOV (código base IBOV ou séries autorizadas)
Armazenamento: SQLite local com histórico de pelo menos 252 dias úteis (para Gamma Score)
Critérios de Aceite:
Script executa sem intervenção manual após configuração inicial
Dados parseados corretamente para ≥95% das séries ativas
Histórico de OI armazenado e consultável por data

F10 — Market Gamma Curve
Descrição: Gerar a curva contínua de gamma agregado para um range de preços hipotéticos.
Algoritmo:
Para S_hyp de (0.80 × F) até (1.20 × F), passo = (0.40 × F) / 200:
    GEX_total = 0
    Para cada opção na chain:
        Γ_hyp = Black76_Gamma(S_hyp, K, σ, T, r)
        Se tipo == 'call':
            GEX_total += OI × Γ_hyp × S_hyp² × 0.01
        Se tipo == 'put':
            GEX_total -= OI × Γ_hyp × S_hyp² × 0.01
    market_gamma[S_hyp] = GEX_total
Regras:
200 pontos mínimos para curva suave
Área verde (acima de zero) = gamma positivo
Área vermelha (abaixo de zero) = gamma negativo

F13 — Classificação de Walls
Descrição: Selecionar os N strikes mais relevantes e atribuir espessura de linha proporcional ao gamma.
Algoritmo:
Filtrar strikes com |GEX_net| > threshold (ex: >5% do max)
Selecionar os 8 strikes mais próximos do spot com OI significativo
Ordenar por |GEX_net| decrescente
Atribuir: 
Width 3 → Top 1 (Wall principal)
Width 2 → Top 2-3 (Walls secundárias)
Width 1 → Top 4-8 (Walls terciárias)
Cor: 
GEX_net > 0 → Call Wall (clLime)
GEX_net < 0 → Put Wall (clLime, mas abaixo do spot)

-- Histórico de Open Interest
CREATE TABLE oi_history (
date , -- 'IBOVJ185000' date TEXT NOT NULL, -- '2026-05-06'
strike REAL NOT NULL, -- 185000.0 (IBOV)
strike_fut REAL, -- 187986.748 (convertido WIN)
option_type TEXT NOT NULL, -- 'CALL' | 'PUT'
expiry TEXT NOT NULL, -- '2026-06-20'
oi INTEGER NOT NULL, -- 45230
settle_price REAL, -- 4.35
iv REAL, -- 0.2847
PRIMARY KEY (date, ticker)
);

-- GEX calculado por data
CREATE TABLE gex_history (
date TEXT NOT NULL,
strike_fut REAL NOT NULL,
gex_call REAL,
gex_put REAL,
gex_net REAL,
gex_current REAL, -- vencimento atual
gex_next REAL, -- próximos vencimentos
PRIMARY KEY (date, strike_fut)
);

-- Métricas diárias
CREATE TABLE metrics_history (
date TEXT PRIMARY KEY,

max_gamma REAL,
min_gamma REAL,
gamma_atm REAL,
gamma_score REAL, -- z-score
call_wall REAL, -- strike da Call Wall principal

);

-- Parâmetros utilizados
CREATE TABLE run_log (
run_id INTEGER PRIMARY KEY AUTOINCREMENT,
timestamp TEXT,

n_options INTEGER,

);

9. Parâmetros Configuráveis (params.yaml)
YAML
# ─── Ativo ───
asset:
future_symbol: "WIN$" # símbolo genérico do WIN no MT5
spot_symbol: "IBOV" # índice spot
contract_multiplier: 0.20 # R$ por ponto no mini-índice

# ─── Modelo ───
model:
type: "black76"
risk_free_rate: 0.1475 # SELIC anual
dividend_yield: 0.045 # DY IBOV estimado
min_T: 0.003968 # 1/252 (mínimo 1 dia útil)

# ─── Filtros ───
filters:
max_otm_pct: 0.30 # remover strikes >30% do spot
min_oi: 10 # remover opções com OI < 10
min_iv: 0.05 # IV mínima aceitável
max_iv: 2.00 # IV máxima aceitável

# ─── Market Gamma ───
market_gamma:
range_pct: 0.20 # ±20% do spot
n_points: 200 # pontos na curva

# ─── Walls ───
walls:
n_walls: 8 # número de Wall lines
n_midwalls: 7 # n_walls - 1
radius_strikes: 10 # strikes acima e abaixo do spot
width_top1: 3 # espessura da Wall principal
width_top2_3: 2 # espessura das secundárias
width_others: 1 # espessura das terciárias

# ─── Gamma Score ───
gamma_score:
lookback_days: 252 # 1 ano de histórico
alert_threshold: 2.0 # alerta se |z-score| > 2σ

# ─── Output ───
output:
format: "begin_end" # formato das linhas para MT5
save_charts: true
chart_theme: "plotly_dark"
